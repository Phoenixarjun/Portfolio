## ✨ About

This is my personal **developer portfolio website**, built with a modern and accessible tech stack to showcase my skills, projects, services, and achievements. It's clean, responsive, and interactive — just like the web experiences I strive to create.

---

## ⚙️ Tech Stack

| Tech          | Purpose                                      |
|---------------|----------------------------------------------|
| **React.js**  | Component-based frontend development          |
| **Tailwind CSS** | Utility-first styling framework           |
| **JavaScript (ES6+)** | Logic, interactivity, and data flow |
| **Framer Motion** | Animations and transitions                |
| **Radix UI**  | Accessible and customizable UI components     |

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Phoenixarjun/Portfolio
cd Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
````
